| Роль | Права роли | Группы пользователей |
| --- | --- | --- |
| `administrator` | Полный доступ (`*`) ко всем ресурсам и действиям во всем кластере. | DevOps-инженеры |
| `analyst` | Только чтение (`get`, `list`, `watch`) ресурсов во всем кластере. | Бизнес-аналитики, Менеджеры |
| `developer` | Управление (`create`, `update`, `patch`, `delete`) объектами в рамках конкретного неймспейса. | Разработчики |
| `security` | Чтение секретов (`secrets`) и сетевых политик (`networkpolicies`) для аудита. | Специалисты по ИБ |



create_cert.sh - создаёт SSL-сертификаты для пользователей  
create_users_with_certs.sh - создаёт пользователя alex из роли developer и пользователя grisha из роли analyst и проверяет работу RBAC-доступа
